# Phosphene Lab

Веб-инструмент для индукции фосфенов мерцающим светом.

## Как запустить

Просто открой `index.html` в браузере. Камера не используется,
поэтому HTTPS и локальный сервер не нужны.

Если браузер блокирует открытие через `file://` — подними
локальный сервер:

```bash
# Если есть Python 3:
python -m http.server 8000

# Если есть Node.js:
npx serve
````

svgsvg

И открой [http://localhost:8000](http://localhost:8000/)

## Как использовать

1. Открой `index.html`
2. Выбери частоту, цвет и длительность
3. Поставь галочку согласия
4. Нажми «Начать эксперимент»
5. В темноте закрой глаза, смотри узоры
6. После завершения — перейди к форме и опиши увиденное

## Настройка формы

Замени ссылку в `js/config.js`:

js

```
yandexFormUrl: 'https://forms.yandex.ru/your-form-id'
```

svgsvg

на URL своей Яндекс.Формы.

## Настройка параметров

Все параметры — в `js/config.js`:

- частоты (слайдер),
- длительности,
- цвета,
- размер вспышки,
- плавность.

## ⚠️ Безопасность

Мерцающий свет 5–15 Гц может спровоцировать приступ
у людей с фотосенситивной эпилепсией. Не запускайте
эксперимент при наличии эпилепсии или мигрени.
